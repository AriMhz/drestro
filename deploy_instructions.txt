# Drestro Deployment Instructions

For **drestro.com** (Landing Page & Admin Portal):
When you upload `latest_updates.zip` to the server and extract it, you must run the following commands to rebuild and restart the server:

```bash
cd /home/drestro/htdocs/drestro.com/
unzip -o latest_updates.zip
npm run build

# CORRECT RESTART COMMAND
npx pm2 restart drestro
```

For **portal.drestro.com** (Livewire POS System):
The exact absolute path on the server is `/home/drestro-portal/htdocs/portal.drestro.com/`

When uploading updates via SCP, use this exact destination:
```powershell
# For zip files:
scp latest_updates.zip drestro-portal@207.180.219.212:/home/drestro-portal/htdocs/portal.drestro.com/

# For a deployment PHP script:
scp deploy_ui_fixes.php drestro-portal@207.180.219.212:/home/drestro-portal/htdocs/portal.drestro.com/public/
```

After uploading, you must ALWAYS clear the cache so the Livewire and Blade views update immediately:
```bash
# In your SSH session (drestro-portal@207.180.219.212):
cd /home/drestro-portal/htdocs/portal.drestro.com/
php artisan optimize:clear
```
