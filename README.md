# 🍽️ Drestro

**Smart Restaurant Management & POS Ecosystem**

An all-in-one restaurant automation platform featuring multi-tenant SaaS management, online subscription billing, and real-time Point of Sale (POS) terminals.

---

### 📦 Platform Overview

- **SaaS Web Portal**: Master admin dashboard, client management, online billing, and restaurant onboarding.
- **POS Subsystem**: High-speed cashier billing, Kitchen Display System (KDS), Waiter ordering, and table management.
